# Security policy

ZEO Creator is pre-release. Report suspected vulnerabilities privately through
GitHub's **Security → Report a vulnerability** flow for this repository. Do not
open a public issue containing credentials, private evidence, unpublished
artifacts, destination account references, or provider receipts.

The package must never receive reusable credentials. If a credential appears in
a ZEO Creator request, response, log, artifact, manifest, proposal, or receipt,
revoke it at the provider and report the exposure immediately.
